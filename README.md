# AI Cultural Events Curator

An automated workflow that generates personalized cultural event recommendations based on user preferences, combining real-time data from the Ticketmaster API with AI-powered descriptions from Google Gemini.

---

## Overview

The user fills out a simple form (city, category, personal style), and receives a curated HTML email with 5 handpicked cultural events — each with a personalized description generated by AI.

**What it does:**
- Collects user preferences via an n8n native form (city, category, artistic style)
- Fetches real, up-to-date events from the Ticketmaster API
- Deduplicates results to ensure variety
- Sends all events in a single Gemini API call for personalized descriptions (optimized to stay within free tier rate limits)
- Delivers a clean, elegant HTML email with images, venue, dates, and a direct link to each event

---

## Workflow Architecture

```
Form Trigger (City, Category, Style)
        |
        ↓
Field Mapping (normalize form fields)
        |
        ↓
Ticketmaster API (fetch 20 events → deduplicate → keep top 5)
        |
        ↓
Format Ticketmaster Data
        |
        ↓
Aggregate Events
        |
        ↓
Prepare Gemini Prompt
        |
        ↓
Gemini AI (single API call → 5 personalized descriptions)
        |
        ↓
Build HTML Email
        |
        ↓
Gmail (delivered to user's inbox)
```

## Key Features

- **Native n8n form** — no external frontend needed, fully self-contained workflow
- **Real event data** — sourced directly from Ticketmaster, with real images and official links
- **Smart deduplication** — fetches 20 results and filters duplicates to ensure 5 unique events
- **Optimized AI usage** — all descriptions generated in a single Gemini API call to avoid rate limit issues
- **Personalized output** — descriptions adapt to the user's artistic style (e.g. jazz, cubism, contemporary)
- **Zero cost** — runs entirely on free tiers (n8n local, Ticketmaster free, Gemini free API)

---

## Email Output

The generated email includes:
- A clean header with city, category, and style
- 5 curated events with image, venue, address, dates
- A 3-sentence AI-generated description personalized to the user's taste
- A direct link to each event on Ticketmaster
- Elegant HTML styling compatible with Gmail (inline CSS, serif typography, bordeaux palette)

## How to Run

1. Clone this repository
2. Import `workflow.json` into your n8n instance
3. Set up your credentials:
   - Ticketmaster API key (free at [developer.ticketmaster.com](https://developer.ticketmaster.com))
   - Google Gemini API key (free at [aistudio.google.com](https://aistudio.google.com))
   - Gmail OAuth credentials (via Google Cloud Console)
4. Open the form URL generated by n8n
5. Fill in your preferences and check your inbox

---

## Known Limitations & Roadmap

- **Expositions** are underrepresented on Ticketmaster (concert-focused platform). A planned improvement is to integrate [Eventbrite API](https://www.eventbrite.com/platform) as a second data source for better cultural event coverage.
- Event deduplication is based on title matching — events with dates in their title (e.g. theatre runs) may still appear multiple times.
- Gemini may occasionally generate generic descriptions for lesser-known events. A future improvement would split the workflow into two Gemini calls: one for web search (factual data) and one for personalized writing.
